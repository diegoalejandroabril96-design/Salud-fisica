# Salud Fisica

App personal de entrenamiento de 30 minutos para mejorar salud y condicion fisica.

## Que incluye

- Rutina de lunes a sabado.
- Division de 3 dias tren superior y 3 dias tren inferior.
- Calentamiento guiado.
- 5 minutos diarios de cuerda progresiva.
- Punto de decision para terminar despues del cardio si el esfuerzo percibido fue suficiente.
- Circuito de fuerza e HIIT adaptado.
- Registro de repeticiones o segundos por ejercicio.
- Objetivos progresivos segun el ultimo resultado.
- Funcionamiento como PWA instalable.

## Uso

Abre `index.html` o publica el repositorio con GitHub Pages desde la rama `main`.

Los datos de progreso se guardan en el dispositivo mediante `localStorage`.
